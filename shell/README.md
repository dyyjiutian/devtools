# Shell 配置

本目录管理 Shell **交互环境**：启动文件、插件、主题和跨 Shell Prompt。

- shell/bash：轻量 Bash 插件。
- shell/zsh：轻量 Zsh 插件。
- shell/oh-my-zsh：Oh My Zsh 与 Powerlevel10k。
- shell/starship：共享 Prompt 配置。

Shell 配置脚本使用 marker，重复执行时会保留已有未托管内容。

写可执行 Bash 脚本时的语言约定、兼容基线与陷阱见 [`languages/bash/`](../languages/bash/)，不要与本目录混淆。
